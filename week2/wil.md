2주차 수업에서는 첫번째로 git clone에 대해 배웠다. 깃허브의 레포지토리 URL만 있으면 git bash 를 통해 어떤 컴퓨터 어떤 위치에서든지 깃허브에 저장된 파일을 복사할 수 있다. 다른 컴퓨터를 사용해야하거나, 파일을 실수로 삭제했을 때 정말 유용한 수단이다. 두번째로 HyperText에 대해 배웠다. HyperText란 텍스트에 링크를 걸어 다른 페이지로 넘어갈 수 있게 하는 것이다. 링클르 걸기위해 a href="파일주소" 텍스트 /a 이런 식으로 사용한다. 다음으로 CSS에 대해 조금 배웠다. style을 통해 문서를 꾸먔다. color는 텍스트의 색을 변경하고, background-color는 텍스트 바깥 배경에 색을 더한다.
