C++

C++은 1983년 비야네 스트롭스트룹이 C 언어를 바탕으로 객체 지향 프로그래밍 기능을 추가하여 만든 프로그래밍 언어이다.

장점

압도적인 성능

컴파일 언어로서 하드웨어 제어 능력이 뛰어나며, 실행 속도가 매우 빠르다.

높은 범용성과 이식성

절차 지향과 객체 지향, 일반화 프로그래밍을 모두 지원하는 멀티 패러다임 언어이다. 다양한 플랫폼에서 표준에 맞게 작성된 코드를 실행할 수 있다.

단점

높은 학습 난이도

문법이 복잡하고 메모리 관리(포인터 등)를 개발자가 직접 제어해야 하는 경우가 많아 숙련되기까지 상당한 시간이 걸린다.

낮은 생산성과 위험성

파이썬과 같은 현대적인 언어에 비해 코드량이 많고 개발 속도가 느리다. 메모리를 직접 다루기 때문에 실수할 경우 프로그램이 비정상 종료되는 등의 오류가 발생하기 쉽다.
