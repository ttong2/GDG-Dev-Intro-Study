## margin

- 바깥 여백을 넣는 코드
- 어떤 요소를 이동할 때, 간격을 줄 때 사용
- 이동하고자하는 방향의 반대방향으로 입력
- 음수 사용 가능

#### 예시
*margin-top: 100px;*
*margin-bottom: 100px;*
*margin-left: 100px;*
*margin-right: 100px;*
*margin:0 auto;*

## padding

- 내용을 안으로 밀어 넣는 코드
- 크기를 늘리면서 간격을 줄 때 사용
- 블럭요소에 width가 선언되지 않았다면 작동하지 않음
- 음수 사용 불가능

#### 예시
*padding-top:100px;*
*padding-bottom:100px;*
*padding-left:100px;*
*padding-right:100px;*
