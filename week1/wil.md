첫째주 수업은 아무래도 수업의 처음이다보니 본격적인 개발 수업이 아닌, 앞으로 개발을 하기 위한 세팅을 했다. 먼저 GitHub와 Versel에 가입하고, git과 VSCode를 설치해야한다. VSCode에서 코드를 작성하여 웹사이트를 꾸미고 git에서 git add file, git commit -m "메시지", git push 등의 명령어를 통해 GitHub에 업로드를 한다. 그리고 Vercel과 GitHub를 연동하여 배포하면 나만의 웹사이트가 완성된다. HTML에서 가장 큰 제목은 h1에서부터 시작해서 h2 h> h4... 순으로 글씨가 점점 작아진다. p로 작은 글씨를 쓸 수 있다. 이미지를 추가하기위해서 img태그를 사용한다. style로 크기, 위치설정과 title로 제목을 설정할 수 있다.
